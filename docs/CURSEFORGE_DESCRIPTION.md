# Forever Mana Tick

See estimated mana and energy tick timing on your default player power bar and personal resource display in WoW Forever.

- A moving spark shows the estimated two-second regeneration cycle.
- A five-second countdown helps you track mana regeneration after spending mana.
- Mana gains appear in blue, energy gains in yellow, and losses in purple when the client allows those values to be read.
- Supports mana users, rogues, and druids in cat form. Cat-form druids can see separate energy and mana timers on the personal resource display.

No additional addons are required. Install it, enable it, and use the default Blizzard player frame. Adjust the spark size under **Esc > Options > AddOns > Forever Mana Tick**; the selection is saved account-wide.

## Compatibility

Targets WoW Forever Interface 16001. Replacement unit frames that hide the default power bar can also stop timing updates.

Timers are estimates. When the client restricts power values, gain and loss text is unavailable. The personal resource display was tested in game; the full client verification checklist is still pending.
