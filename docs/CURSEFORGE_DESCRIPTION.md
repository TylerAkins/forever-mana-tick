# Forever Mana Tick

See estimated mana and energy tick timing right on your default player power bar in WoW Forever.

- A moving spark shows the estimated two-second regeneration cycle.
- A five-second countdown helps you track mana regeneration after spending mana.
- Mana gains appear in blue, energy gains in yellow, and losses in purple when the client allows those values to be read.
- Supports mana users, rogues, and druids in cat form.

There are no settings to configure and no additional addons required. Install it, enable it, and use the default Blizzard player frame.

## Compatibility

Built for the WoW Forever beta client. Custom unit frames that hide the default power bar will also hide these indicators.

Timers are estimates. When the client restricts power values, gain and loss text is unavailable. In-game verification of this release is still pending.
